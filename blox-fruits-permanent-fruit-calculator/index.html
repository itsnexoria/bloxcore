FAQ

What is the difference between physical and permanent value?

Permanent fruits are listed with their own, separate value from physical copies, and it is usually much higher. Always confirm which one a trade is using — mixing them up is the easiest way to get a bad deal.

How many physical fruits equal one permanent fruit?

Divide the permanent value by the physical value — the last column does this for every fruit using current values. Permanent and physical values are on very different scales, so the multiplier is large.

Why do the numbers change?

Values are community estimates that move with demand, so this table is rebuilt whenever the value list updates.
